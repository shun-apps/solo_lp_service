# 個人事業主向けLP＋受付管理：操作体験版

整体院向け管理画面の操作感を引き継いだ、コンテンツ販売者・ハンドメイド作家・小規模講師向けの**独立した製品デモ**です。

## リポジトリ・公開環境

- GitHub: `shun-apps/solo_lp_service`（個人事業主専用）
- Cloudflare Workers: **`solo-lp-demo`**（整体院版 `seitai-lp-demo` と別Worker）
- 本番ブランチ: `main`（テスト通過後にマージ）
- GitHub連携のCloudflare公開URLは、初回Worker作成後に発行されます
- 整体院版・瞬LP V2のソース、Worker、DBやGoogle設定には一切触れません
- 公開デモは静的データで動く操作体験版。実イベント申込や実問い合わせの受付ではありません

## 提供画面

- ダッシュボード（LP 3本・イベント件数・申込件数・未対応お問い合わせ）
- LP管理（オンライン講座／ハンドメイド／ワークショップの**仮見本**3本）
- イベント管理（日付・時間・定員・公開ON/OFF、イベント追加・編集）
- 申込・お問い合わせ（イベント参加申込とお問い合わせの別タブ、キャンセル・対応済み操作）
- フォームの設定（イベント申込／お問い合わせの既定フォーム切り替え）
- 自動返信メール（**送信しない**プレビュー）
- 事業者情報（サンプル事業者名の変更）

## 2種類の疑似体験

### イベント申込
フォームの種類を選ぶ → LPの流入元を選ぶ → 開催イベントを選ぶ（残席を表示） → 架空のお客様情報を確認 →「送信を確定する（デモ）」 → 完了画面で通知文を見る → 管理画面に戻る。

申込数が増え、残席が減る。定員に達したイベント・受付停止中のイベントでは申し込めない。

### お問い合わせ
フォームの種類を選ぶ → LPの流入元を選ぶ → 問い合わせの種類を選ぶ → 架空のお客様情報を確認 →「送信を確定する（デモ）」→ 管理画面の問い合わせ一覧に新着が増える。対応済み状態を変更できる。

## セキュリティとデータ

- 顧客の実名、実メール、電話番号を入力させない
- 予約・問い合わせは**そのブラウザのメモリにのみ存在**。他の閲覧者と共有しない
- \`localStorage\`、\`sessionStorage\`、DB、Google、実際のメール、外部APIへの送信なし
- 再読込で初期状態に戻る
- Cloudflare WorkerはGET/HEAD以外405、\`/api/*\` は404、CSPで送信禁止
- \`noindex\` を設定。正式営業サイト完成後に別途見直す

## 販売条件（ユーザー方針を記録、実装は別）

- 対象：年商1,000万円程度の個人事業主／コンテンツ販売者／ハンドメイド作家／講師等
- 完全後払い：完成後に内容を確認してから支払う
- **完成案内から24時間以内の入金で40,000円**（税込・税別未確定）
- 通常価格、24時間後の取扱い、キャンセル期限、正式納品のタイミングは販売開始前に明文化する
- 未払いのままZIP・編集可能なソースを正式譲渡すると未回収のリスクがあるため、**完成プレビューと正式納品は分離**することを推奨
- 商品・納品範囲、修正回数、サーバー費用、イベント通知やスプレッドシート連携の有無は販売前に決める
- このデモ管理画面に販売コピーや価格表を押し込まず、営業導線は別に用意する
